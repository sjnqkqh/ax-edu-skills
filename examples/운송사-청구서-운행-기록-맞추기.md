# 가상 문제 상황

- 직종: 물류

## 운송사 청구서와 운행 기록 맞추기

### 선정 이유
매일 아침 유입되는 협력 운송사의 청구서 내역과 내부 운행 일지 간의 불일치로 인해 정산 지연 및 과지급 전표 재작업이 반복되는 전형적인 물류 회계 병목 업무입니다.

### 배경 설명
중소 3자물류(3PL) 회사에서 회계 담당자가 협력 운송사들의 일일 운행 정산 업무를 전담하고 있습니다. 매일 아침 전날 운행 건에 대한 청구 내역서 PDF와 현장 인수증 스캔 파일이 담당자 이메일로 다량 접수됩니다. 담당자는 회계 시스템에 지급 전표를 입력하기 전, 내부 배차 관리 시스템에서 내려받은 실제 운행 일지 엑셀 데이터와 청구 내역을 한 줄씩 대조해야 합니다.

협력 운송사는 여러 곳이며 동일 차량이 하루에도 여러 물류 구간을 왕복 운행합니다. 이로 인해 청구서 PDF 상의 청구 행과 내부 운행 일지 엑셀의 배차 행이 시간순이나 차량번호순으로 일치하지 않아 대조 작업에 많은 시간이 소요됩니다.

### 구체적 제약 사항
1. 매일 아침 협력 운송사로부터 40장의 청구서 PDF가 유입됩니다.
2. 청구서 1장당 배차 대조 및 검토 소요 시간은 평균 12분입니다.
3. 각 PDF 문서에는 차량번호, 출발지, 도착지, 기본운임, 대기/경유 할증료 항목이 행 단위로 기재되어 있습니다.
4. 담당자는 각 청구 행을 당일 내부 배차 운행 일지 엑셀 파일에서 직접 검색하여 대조합니다.
5. 단일 차량이 동일 일자에 복수 구간을 운행한 경우 어느 청구 행이 실제 어느 배차 건에 해당하는지 즉시 확인하기 어렵습니다.
6. 현장 인수증 스캔 파일에 수기 날인된 도착 시각과 청구서 PDF 상의 야간/대기 할증 명칭 표기가 서로 상이한 경우가 빈번합니다.
7. 대조 과정에서 구간이나 금액이 일치하지 않는 청구서는 당일 지급 승인이 보류됩니다.
8. 전체 40장 중 약 20%는 배차 누락, 구간 상이, 할증 기준 불일치로 보류되거나 재확인 대상이 됩니다.
9. 보류된 청구서는 익일 동일 금액으로 다시 청구되어 중복 검토 대상이 됩니다.
10. 불일치를 인지하지 못하고 지급된 건은 과지급 전표로 처리되어 익월 상계 처리 초안 작성이라는 추가 수작업을 유발합니다.

### 이 상황이 문제인 이유
담당자는 매일 청구서 PDF를 열어 차량번호, 운행 구간, 청구 운임을 확인한 뒤, 내부 운행 일지 엑셀에서 해당 차량의 운행 내역을 수작업으로 검색·대조하는 반복 업무에 과도한 시간을 투입하고 있습니다.

이 업무는 근무일 20일 기준 187시간이 소요되며, 이를 월 단위로 환산하면 467만 원의 비용이 발생한다.

### 비용 가정
- 하루 건수: 40장
- 1건 처리 시간: 12분
- 시간당 회사부담 인건비: 25,000원
- 재작업 비율: 20%
- 1건 재작업 시간: 10분

### 기존 비용
- 시간당 회사부담 인건비: 25,000원
- 일 처리 인건비: 200,000원
- 일 재작업 인건비: 33,333원
- 일 총발생비용: 233,333원
- 월 총발생비용: 4,666,660원

### 이 상황을 다시 만들 때 필요한 입력
- 청구서번호: 문자열
- 운송사명: 문자열
- 청구일자: 날짜
- 차량번호: 문자열
- 출발지: 문자열
- 도착지: 문자열
- 청구운임: 원
- 할증료: 원
- 운행일지_배차번호: 문자열
- 운행일지_실제운임: 원
- 인수증_수기확인시각: 시간
- 대조결과: 문자열 (일치, 보류_금액불일치, 보류_배차누락, 보류_할증상이)
