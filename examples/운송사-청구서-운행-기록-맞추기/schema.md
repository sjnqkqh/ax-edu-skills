# 데이터 및 서류 명세서 (Schema)

## 1. data/day_inbox.csv (당일 청구 접수 인덱스)
| 필드명 | 데이터 타입 | 설명 및 실무자 대조 목적 |
| --- | --- | --- |
| invoice_no | 문자열 | 청구 건의 고유 식별 번호 (예: INV-20260901-001) |
| carrier_name | 문자열 | 협력 운송사 상호명 |
| invoice_date | 날짜 | 청구 발행 일자 |
| pdf_path | 상대경로 | 청구서 PDF 파일 경로 (`invoices_pdf/INV-...pdf`) |
| receipt_path | 상대경로 | 현장 화물 인수증 JPG 파일 경로 (`receipts_jpg/RCP-...jpg`) |

## 2. data/invoices_pdf/*.pdf (비정형 청구서 PDF 명세)
- **문서 규격**: A4 단면 표준 청구서
- **포함 항목**:
  - `차량 번호`: 운행 차량 번호 (예: 11가1017)
  - `운행 구간`: 출발지 및 도착지 (예: 용인백암센터 → 쿠팡이천물류)
  - `기본 운임`: 운송 계약 기본 청구액 (원)
  - `할증 구분`: 야간운행할증, 하차대기할증 등 비고 및 청구액 (원)
  - `합계 청구액`: 공급가액 기준 총 청구금액 (원)

## 3. data/receipts_jpg/*.jpg (현장 인수증 스캔 JPG 명세)
- **문서 규격**: 현장 출력 서식 스캔 이미지 (JPEG)
- **포함 항목**:
  - `하차 일시`: 실제 차량 도착 및 하차 완료 시각 (수기/전산 기재)
  - `인수 비고`: 야간/대기 등 현장 할증 발생 승인 사유
  - `물류 검수 날인`: 물류센터 입고 담당자의 붉은색 검수 직인
- **현장 노이즈**: 실제 모바일 촬영 및 팩스 스캔 환경을 모사하여 일부 파일에 90도/270도 회전 노이즈 포함

## 4. data/dispatch_lookup.csv (내부 배차 관리 시스템 승인 데이터)
| 필드명 | 데이터 타입 | 설명 및 대조 목적 |
| --- | --- | --- |
| dispatch_id | 문자열 | 내부 승인 배차 번호 |
| dispatch_date | 날짜 | 배차 운행 일자 |
| vehicle_no | 문자열 | 승인된 배차 차량번호 |
| route | 문자열 | 승인 운행 경로 (출발->도착) |
| approved_freight | 정수(원) | 사전 승인된 계약 기본운임 |
| approved_surcharge | 정수(원) | 사전 승인된 할증운임 |
| status | 문자열 | 운행 완료 상태 (운행완료 등) |
