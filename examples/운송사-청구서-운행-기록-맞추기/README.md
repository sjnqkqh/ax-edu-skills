# 운송사 청구서(PDF)와 현장 인수증(JPG) 대조 실습

## 1. 업무 배경 및 문제 정의
중소 3자물류(3PL) 회사의 회계 담당자는 매일 아침 협력 운송사로부터 40장의 운행 청구서 PDF 파일과 현장 화물 인수증 JPG 스캔본을 수령합니다.
담당자는 PDF 청구서의 차량번호, 운행구간, 기본운임, 할증료를 열람하고, JPG 인수증의 수기 도착 시각 및 검수 날인을 확인한 뒤 내부 배차 운행 일지 엑셀 데이터와 한 줄씩 수작업으로 대조합니다.

비정형 문서의 서식 차이, 일부 스캔 파일의 회전(90도/270도) 현상, 청구 운임과 내부 승인 운임 간의 불일치로 인해 매일 약 20%의 지급 보류 및 재작업이 발생하고 있습니다.

## 2. 과제 목표
본 실습의 목표는 담당자가 겪고 있는 비효율적인 수작업 대조 프로세스(읽기 → 나누기 → 찾아보기 → 초안 작성)를 이해하고, 비정형 바이너리 문서(PDF, JPG)를 자동으로 파싱·대조하여 재작업률을 낮추고 월 467만 원에 달하는 인건비 손실을 절감하는 솔루션을 설계·구현하는 것입니다.

## 3. 디렉토리 구조
```text
운송사-청구서-운행-기록-맞추기/
├── README.md                     # 실습/과제 안내서
├── schema.md                     # 데이터 필드 및 바이너리 서류 구조 명세
├── data/
│   ├── day_inbox.csv             # 당일 접수된 청구 건 목록 (PDF 및 JPG 파일 경로)
│   ├── invoices_pdf/             # 협력 운송사 발행 실제 청구서 PDF 40건
│   ├── receipts_jpg/             # 현장 검수인 날인 및 도착시간 기재된 인수증 JPG 40건 (일부 회전 노이즈 포함)
│   ├── dispatch_lookup.csv       # 내부 승인 배차 일지 마스터
│   └── rework_log.csv            # 이전 발생한 지급 보류/재작업 이력
├── hidden/                       # 채점 및 평가용 기준 데이터 (실습생 열람 제한)
│   ├── ground_truth.csv          # 정답 매핑표 및 회전 각도 레이블
│   └── cost_assumptions.json     # 인건비 및 소요 시간 파라미터
└── reconcile_carrier_invoices.py # 수작업 4단계 바이너리 대조 재현 스크립트
```

## 4. 필요한 패키지 및 스크립트 실행 방법
본 실습 스크립트는 PDF 및 이미지 처리를 위해 `PyMuPDF`와 `Pillow`를 사용합니다.

```bash
# 의존성 설치
pip install PyMuPDF pillow

# 재현 스크립트 실행
python reconcile_carrier_invoices.py
```
