# AX 합성 데이터 재현

가상 문제 상황 하나를 받아, 학생이 그 장면을 실제로 겪을 수 있게 합성 데이터와 재현 스크립트를 만든다. AX 해결책, 자동화, 에이전트는 넣지 않는다. 문제의 현재 모습만 재현한다.

## 입력
직전 스킬이 남긴 마크다운 파일(고른 상황 하나)을 받는다. 파일이 있으면 그 내용으로 채운다. 선정 이유가 있으면 실패·애매함을 심을 때 그 방향을 따른다. 새 사실은 짓지 않는다.

파일이 없고 아래가 없으면 부족한 항목만 묻고 멈춘다.
- 상황 이름
- 배경 설명
- 구체적 제약 사항
- AX 전환이 필요한 이유
- 비용 가정: 하루 건수, 1건 처리 시간(분), 시간당 회사부담 인건비, 재작업 비율, 1건 재작업 시간(분)
- 기존 비용
- 이 상황을 다시 만들 때 필요한 입력

여러 상황이 한꺼번에 오면 고르기 스킬로 보낸다. 여기서 목록을 고르게 하지 않는다.

## 목표
1. 매일 반복 장면을 데이터로 재현한다.
2. 사람이 읽고 나누고 찾아보고 초안을 쓰는 구간이 스크립트에 드러난다.
3. 재작업이 데이터에 심겨 있고, 틀리면 일이 다시 생긴다.
4. 비용 가정의 규모(하루 건수, 재작업 비율)와 데이터가 맞는다.
5. 학생은 이 산출물을 돌려 보고 병목을 느낀 뒤, 스스로 AX를 붙인다.

## 산출물 구조
한 상황당 폴더 하나. 파일 이름은 장면 용어에 맞게 바꿔도 되지만 역할은 유지한다.

```
<상황폴더>/
  README.md
  schema.md
  data/
    day_inbox.csv
    lookup.csv
    rework_log.csv
  hidden/
    ground_truth.csv
    cost_assumptions.json
  replay.py
```

- `data/`: 사람이 현장에서 보는 입력. 정답 라벨 없음.
- `lookup.csv`: 찾아보는 대상이 있을 때만.
- `rework_log.csv`: 실패 시 다시 생기는 일이 있을 때만.
- `hidden/ground_truth.csv`: 평가용. 재현 스크립트는 읽지 않는다.
- `hidden/cost_assumptions.json`: 비용 가정과 기존 비용.
- 첨부 파일(PDF, JPG 등)이 있는 장면에서는 첨부를 다시 만드는 스크립트를 두어도 된다. 학생이 과제로 실행하는 파일은 `replay.py`다.

## 데이터 규칙
- 하루 건수만큼 입력 행을 만든다. 기본은 1일치. 사용자가 기간을 주면 그 일수 × 하루 건수.
- 재작업 비율만큼 실패·재작업 케이스를 심는다. 정답 표시는 `hidden/ground_truth.csv`에만 둔다. `data/`에는 사람이 보듯 애매함, 누락, 유사 이름, 형식 불일치 같은 표면만 남긴다. 그 표면은 의도다. 글자가 잘려 못 읽히거나, 파일이 열리지 않거나, 한 운영체제에서만 만들어지는 PDF, JPG는 의도가 아니다.
- 필드 목록은 상황의 "다시 만들 때 필요한 입력"을 따른다. 없는 필드를 지어 넣지 않는다. 장면 재현에 꼭 필요한 보조 필드만 최소로 추가하고 `schema.md`에 이유를 적는다.
- 칸 이름과 칸에 넣는 값 모두 상황에서 쓰는 말로 쓴다.
- 실존 개인, 실존 회사, 실무 기밀을 쓰지 않는다. 가상 고유명사를 쓴다.
- 같은 형태가 반복되어야 한다. 행마다 스키마가 바뀌면 안 된다.
- 사람이 보는 텍스트(본문, 메모, 문의)는 짧지 않게 쓴다. 읽고 나누는 비용이 느껴져야 한다.
- 입력 파일 형식(엑셀, PDF, JPG 등)이 상황에 있으면 데이터와 설명에 그대로 남긴다. 현장에서 글자를 읽는 파일이면 파일 안에 글자가 있어야 한다. `replay.py`가 표준 라이브러리로 열어야 하는 표는 CSV로 두어도 된다.
- 사진이나 스캔(JPG 등)이 있는 장면에서는 현장에서 찍은 것처럼 일부를 구기고, 일부는 90도·180도·270도로 돌아가 있게 만든다. 전부가 아니라 일부다. 작은 기울기는 구김과 함께 섞어도 된다. 구김은 종이의 주름·그림자처럼 보이게 한다. 글자를 가리는 낙서로 대신하지 않는다. 구김과 돌아간 각도는 정답이므로 `data/`에 적지 않고 `hidden/ground_truth.csv`에만 둔다.
- PDF의 줄바꿈은 그려지는 너비로 한다. 글자 개수로 잘라 단위나 단어가 중간에서 떨어지지 않게 한다.

## 스크립트 규칙
- 언어는 Python 3.
- `replay.py`는 표준 라이브러리만 쓴다. 추가 패키지를 기본으로 두지 않는다. 학생이 `python replay.py`만으로 장면을 돌릴 수 있어야 한다.
- `replay.py`는 현재 업무 그대로의 재현이다. 분류 모델, 대규모 언어 모델 호출, 자동화 정답을 넣지 않는다.
- 한 건을 처리할 때 아래 구간이 로그로 보여야 한다.
  1. 읽기: 원문에서 무엇을 보는지
  2. 나누기: 어떤 칸으로 쪼개는지
  3. 찾아보기: 어떤 표나 파일을 대조하는지
  4. 초안: 사람이 쓰는 결과물의 빈 칸 또는 미완성 초안
- 초안은 의도적으로 불완전하거나 규칙만 흉내 낸다. 정답 매핑을 `hidden/`에서 읽어 완성하지 않는다.
- 재작업 조건이 보이면 새 할 일을 다시 대기열에 넣거나 재작업으로 기록한다.
- 표나 CSV가 가리키는 파일은 `--data` 폴더 안에서만 연다. 상위 경로나 절대 경로를 따라가지 않는다.
- 끝나면 건수, 재작업 건수, 가정 시간·비용을 출력한다. 시간은 실제 시계 시간이 아니라 비용 가정의 분/건을 건수에 곱한 추정치다. 건수와 재작업 건수는 입력 행에서 센다. 하루 건수 숫자를 출력 문자열에 박아 두지 않는다. 수식은 내부에서만 쓰고, 출력에는 숫자와 짧은 근거만 둔다.
- 실행: `python replay.py`가 기본이다. `--data`로 입력 경로를 바꿀 수 있게 한다.
- PDF, JPG처럼 첨부가 있는 장면에서는 그 파일을 다시 만드는 스크립트를 둘 수 있다. 그림, 문서 패키지는 그 스크립트에만 쓴다. 패키지가 필요하면 파일을 다시 만들 때만 필요하다고 적는다. `replay.py`와 README.md의 기본 실행에는 넣지 않는다.
- PDF, JPG를 다시 만드는 일은 지금 쓰는 컴퓨터에서 돌아가야 한다. 한 운영체제의 글꼴 절대 경로에 묶지 않는다. 글꼴은 산출물에 넣거나 여러 흔한 경로에서 찾는다.
- 서로 독립인 장, 쪽은 나눠 만든다. 현장에서 글자를 읽는 파일은 그 형식으로 쓰고, 사진, 스캔은 사진 형식으로 쓴다. 전면을 큰 비트맵으로 그린 뒤 PDF로 저장하지 않는다.
- 다시 만들 수 있게 난수 시드를 고정한다.

## README.md
학생이 읽는 한국어 문서.
- 이 장면이 무엇인지 한 단락. 답을 쓰지 않는다.
- 실행 방법. 기본은 `python replay.py`다. 파일을 다시 만드는 스크립트가 있으면, 데이터를 다시 만들 때만 추가 패키지가 필요하다고 적는다.
- 폴더 설명. `hidden/`은 채점자용이며 풀 때 보지 말 것
- 과제로 무엇을 자동화하면 되는지 한 줄. 어떻게는 쓰지 않는다.

## schema.md
필드 이름, 형식, 예시, 사람이 이 칸을 보는 이유.

## 작성 순서
1. 입력된 상황이 한 개인지 확인한다.
2. 비용 가정과 "다시 만들 때 필요한 입력"을 `hidden/cost_assumptions.json`과 `schema.md`로 고정한다.
3. `data/`와 PDF, JPG, `hidden/ground_truth.csv`를 생성한다. 파일이 열리는지, 장면의 글자가 보이는지 확인한다.
4. `replay.py`를 작성하고 한 번 실행한다. 출력 건수가 입력 행 수와 같고, 재작업 건수가 가정 비율과 맞으며, 출력 비용이 가정 분/건 × 그 건수인지 확인한다.
5. `README.md`를 쓴다.
6. 실행 결과 요약(파일 목록, 건수, 재작업 건수, 출력된 비용)을 보고한다.

## 자기 점검
내기 전에 확인한다.
- `replay.py`가 `hidden/`을 읽지 않는가.
- `replay.py`에 추가 패키지가 없는가.
- 출력 건수·비용이 입력 행과 비용 가정에서 계산되는가.
- PDF, JPG가 그 형식으로 열리고, 현장에서 글자를 읽는 파일이면 글자가 들어 있는가.
- PDF, JPG를 다시 만드는 스크립트가 한 글꼴 경로에 묶이지 않았는가.
- 칸 값에 없는 분류 이름이 없는가.
- 정답 라벨이 `data/`에 없는가.

## 하지 말 것
- 해결 설계, AX 구성, 프롬프트, 에이전트 그림
- 정답을 `data/`나 스크립트 출력 초안에 넣기
- 실무 기밀, 실존 개인정보
- 비용 수식을 사용자 결과물에 반복해서 적기
- 없는 합성어, 줄임 제목, 새 분류 이름을 칸 이름이나 칸 값에 넣기
- `replay.py`에 그림, 문서 패키지를 넣기
